In this week we use the [Scratch programming environment](https://scratch.mit.edu).  Scratch uses block-based programming to enable student to create and share stories, games, and animations while learning the fundamentals of computer science.

![The Scratch Programming Environment](/images/scratch.png)

This week's sessions will be led by Dr. Nathan Bean of the Kansas State University Department of Computer Science.
